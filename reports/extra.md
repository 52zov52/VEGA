# Дополнительные идеи (критерий, доп. баллы)

Всё ниже — сверх базы, с честными оговорками в интерфейсе.

## 1. Прогноз NDVI (экспериментальный)

- `GET /api/analyze/{id}/forecast?horizon=14`: недавний тренд (МНК по 12 точкам,
  клип ±0.05/шаг), смешанный 50/50 с ходом климатологии + коридор ±σ√h
  (мин 0.02, макс 0.25). Шаг дат определяется из ряда (день/неделя).
- На странице анализа — мини-график: факт + пунктирный прогноз + заливающийся
  коридор. Подпись: «эвристика для планирования выездов, не диагноз».
- Горизонт ограничен ~3 месяцами (шаг × число шагов ≤ 90 дней): прогноз
  в зиму на полгода — бессмысленная «линия ради линии».
- Панель даёт текстовый вывод (рост/снижение/плато, дельта, коридор)
  и таблицу значений по датам — не только линию.
- Тест: монотонность дат, lo≤ndvi≤hi, расширение коридора, продолжение тренда.

## 2. Недобор биомассы за сезон

- Один KPI в полосе статистики: Σ max(0, норма − факт) / Σ норма × 100%.
  0% = шли по норме. Эвристика, подписана как эвристика.

## 3. Экспорт анализа в CSV

- Кнопка «⬇ CSV» в шапке страницы анализа: ряд (дата, NDVI, норма, осадки,
  флаг) + строки прогноза. Файл `<id>_analysis.csv`, собирается в браузере.

## 4. Заодно: NaN → 500 (найдено тестом прогноза)

- Крошечные окна анализа давали NaN в KPI → падение JSON-сериализации.
  Теперь неконечные числа превращаются в null. Контракт «никогда 500» держится.
