# Детекция аномалий вегетации (критерий «Детекция аномалий», 0–7)

## Метод (`services/anomaly/detector.py`)

1. **Норма** — климатология NDVI по дню года (окно ±7 дней): `zscore = (факт − норма)/разброс`.
   Проверка: корреляция нашего z с `ndvi_zscore` организаторов — **0.975**.
2. **6 сигналов** (сила негативного отклонения, 0..1): NDVI, EVI, NDWI, погода
   (жара + дефицит осадков), влажность почвы, скорость падения NDVI. Веса из `.env`
   (`ANOMALY_W_*`, по умолчанию 0.35/0.15/0.15/0.15/0.10/0.10).
   Доверие пиксельным сигналам масштабируется качеством данных: облачная точка
   не может дать critical.
3. **Оценка** `anomaly_score` — взвешенная сумма; **уровень** — парой условий
   (z и score). Пороги откалиброваны по разметке `status` из train:
   critical (z<−2, score>0.5, precision 1.0), stress (z<−1.2, score>0.3),
   watch (z<−0.8, score>0.15). Переопределяются через `ANOMALY_Z_*/ANOMALY_S_*`.

## Нетривиальные случаи (что умеет детектор)

| Кейс | Поведение |
|---|---|
| Ранний слабый сигнал | watch-события (`early_warning`), не теряются |
| Эпизод с просветом (облако/шум внутри засухи) | склейка при просвете ≤2 шагов (`VEGA_MERGE_GAP`) |
| Одиночный всплеск | `kind=spike`, уверенность ×0.9 |
| Одиночный всплеск на облаках (quality<0.3) | понижение до watch, `kind=uncertain` |
| Низкое среднее качество эпизода (<0.4) | `kind=uncertain`, пометка в нарративе |
| Восстановление после эпизода | `recovered` + `recovery_date`, фраза в объяснении |
| Своё падение тянет среднее соседей | `neighbour_deviation` строго по ДРУГИМ полигонам |

## Интерпретация (`services/explanation/explainer.py`)

Детерминированные сценарии §18: засуха (0.82), водный компонент (0.74),
локальная проблема поля (0.71), артефакт облачности (0.55), неизвестно (0.6).
Факторы сортируются по силе; шум NDWI (±3) причиной не считается.
Нарратив содержит: отклонение %, длительность, восстановление, оговорку о качестве.
Карточка объяснения получает уровень и даты эпизода (раньше показывала «Норма»
и пустые даты — исправлено).

## Калибровка по разметке организаторов (train `status`, 30520 точек)

| Правило | Precision | Recall |
|---|---|---|
| Было (stress+critical) | 1.000 | 0.010 — детектор почти слепой |
| Стало: stress+critical | 0.996 | 0.050 |
| Стало: любой флаг (incl. watch) | 0.763 | 0.404 |

Критические срабатывания точны (precision 1.0), watch — чувствительный ранний
слой. Recall ограничен осознанно: часть меток «Угнетение» — сезонная норма
низкой биомассы, а не события; гнаться за 100% recall значило бы топить
точность ложными тревогами.
